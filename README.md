## Features

1. Password length analysis.
2. Uppercase and lowercase detection.
3. Number and symbol detection.
4. Repeated character detection.
5. Sequential pattern detection.
6. Password strength classification.
7. Suggestions for improvement.

## Privacy

 Password analysis is performed locally in the browser. The project does not intentionally send passwords to an external server or API.
